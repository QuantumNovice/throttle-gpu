class ThermalGuard(builtins.object)
    ThermalGuard(max_temp_c: 'float' = 85.0, *, interval_s: 'float' = 1.0, consecutive: 'int' = 2, warn_temp_c: 'float | None' = None, on_warning: 'Callable[[float, float], None] | None' = None, source: 'TemperatureSource | None' = None) -&gt; 'None'
 
Context manager that stops the ``with`` block when a GPU overheats.
 
A background thread samples the GPU temperature. When the limit is breached, the
main thread receives ``KeyboardInterrupt``, and the guard turns it into
``ThermalLimitExceeded`` when the block exits. Call ``check()`` inside long loops to
stop at a known point instead.
 
Limitation: Python only runs the interrupt between bytecodes. A call that blocks
inside native code, such as a long CUDA kernel sync, is not interrupted until it
returns. For a hard stop, use ``run_isolated()`` or the ``throttle-gpu run`` command,
which terminate the work process.
 
Example::
 
    with ThermalGuard(max_temp_c=83, consecutive=3):
        train_model()

run_isolated(target: 'Callable[..., Any]', args: 'Sequence[Any]' = (), kwargs: 'Mapping[str, Any] | None' = None, *, max_temp_c: 'float' = 85.0, interval_s: 'float' = 1.0, consecutive: 'int' = 2, source: 'TemperatureSource | None' = None) -> 'Any'
Run ``target(*args, **kwargs)`` in a child process, stopping it on overheat.
 
The child runs under the ``spawn`` start method, which is the safe choice for CUDA
on every platform. ``target`` must be a module-level function, and its arguments
and return value must be picklable.
 
Returns the target's return value. Re-raises the target's exception if it fails.
Raises ``ThermalLimitExceeded`` after killing the child if the limit is breached.
 
Args:
    target: Module-level callable to run.
    args: Positional arguments for ``target``.
    kwargs: Keyword arguments for ``target``.
    max_temp_c: Trip when a GPU is hotter than this (°C).
    interval_s: Seconds between temperature samples.
    consecutive: Over-limit samples in a row required to trip.
    source: Temperature source. Defaults to ``default_source()``.
