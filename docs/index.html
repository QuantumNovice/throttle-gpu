throttle-gpu

Python API reference and practical examples for monitoring NVIDIA GPU temperature and stopping workloads before they exceed a chosen limit.

Install

Install the package directly from GitHub with pip:

python -m pip install "git+https://github.com/QuantumNovice/throttle-gpu.git"

For the optional NVML backend, install the nvml extra. Without it, the package reads temperatures through the NVIDIA driver's nvidia-smi command.

python -m pip install "throttle-gpu[nvml] @ git+https://github.com/QuantumNovice/throttle-gpu.git"

Why this is useful on an MSI Raider GE78

The Raider GE78 HX is sold in configurations with NVIDIA GeForce RTX Laptop GPUs. Long CUDA training, rendering, or other sustained GPU workloads can keep the GPU busy for extended periods. throttle-gpu lets you set a temperature limit and stop a Python block or command when the GPU crosses it. See MSI's Raider GE78 HX product overview. Configurations vary. This tool monitors the GPU sensor and stops work. It does not control fans or replace built-in thermal protections.

Protect a Python training block

Use ThermalGuard to monitor temperature while a block runs. Set a warning threshold below the stop limit if you want time to react.

from throttle_gpu import ThermalGuard, ThermalLimitExceeded

try:
    with ThermalGuard(max_temp_c=83, warn_temp_c=78):
        train_model()
except ThermalLimitExceeded as exc:
    print(f"Training stopped: {exc}")

Guard a training command

Wrap a script or other process when you need the monitor to stop the workload independently of the Python code inside it.

throttle-gpu run --max-temp 83 -- python train.py
